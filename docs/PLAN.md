## 2. 3D素材の方針(ハイブリッド)
- **地形・小物・敵・背景 = 既存アセット優先**(Quaternius / Kenney = CC0無料、Synty・Fab等の有料パック)。プロ製でアニメ付き、統一感が出る。ライセンス(ゲーム内利用・改変可、クレジット要否)を購入前に確認
- **プレイヤー2体 = AI 3D化とアセットを比較テストして決める**(Phase 2後に1体だけ試作)。どちらも不満なら外注(ココナラ/Skeb等)を選択肢に
- AI 3D化の弱点: 関節の曲がりが崩れやすい、手や顔が甘い、ポリゴンが汚い。横スクロールでキャラが小さく映るため目立ちにくい
- AI 3D化の作業分担: あなた=画像生成・3D化サイトとMixamoの操作・出来の選別 / Claude=プロンプト作成、Blenderスクリプト(自動で軽量化・サイズ調整・アニメ統合)、Godotへの組み込み

## 2-2. AI 3D化の手順(自作する場合)

原作DSは「3Dキャラ+横スクロール(2.5D)」。同じ構成にする。

**推奨パイプライン(全部モデリング不要)**
1. **画像生成** でキャラの「三面図(正面・横・背面、Tポーズ)」を作る
2. **画像→3D変換AI**(Meshy / Tripo / Hunyuan3D など)で3Dモデル(.glb)化。テクスチャ付きで出る
3. **自動リグ+アニメーション**: Mixamo(無料)または Meshy/Tripoの自動リグ機能で骨を入れ、走る・ジャンプ・被ダメ等のモーションを付ける
4. Godot に .glb をドラッグするだけで読み込み、アニメーションを再生
5. ポリゴン数はスマホ向けに 5千〜1万程度に削減(変換AIの設定で指定)

- 地形・ブロック・土管は単純形状なのでGodot上で箱や円柱を組み合わせ、画像生成したテクスチャを貼る(3D変換不要)
- 背景は画像生成した1枚絵を奥に置く(多層スクロール)
- 敵・アイテムはキャラと同じパイプライン。小物(コイン・スター)は形が単純なので箱/円柱+テクスチャでも可
- **最初は仮素材(色つきの箱)で全ルールを完成させ、見た目は後で差し替える**。これが初心者でも完成させる最大のコツ

## 4. 技術構成
- **エンジン: Godot 4(GDScript)** — 無料、スマホ出力可、シーン/コードがテキストなので私(Claude)が大部分を書ける
- **表示**: 3Dモデル+横固定カメラ(2.5D)。当たり判定・物理は2D平面上で扱う
- **操作**: 画面左に仮想スティック/十字、右にジャンプ・ダッシュ(ファイア)ボタン。下入力+空中でヒップドロップ
- **CI/CD**: GitHub Actions
  - Android: Linuxランナーで APK/AAB をビルド → エンジニアが実機で確認
  - iOS: macOSランナーで Godot→Xcodeプロジェクト出力→fastlaneで署名・TestFlight アップロード
  - 必要: Apple Developer Program(年額有料)、証明書・プロビジョニング・App Store Connect APIキーをGitHub Secretsに登録(手順はPhase 1で案内)
