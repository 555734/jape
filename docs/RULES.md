# ルール仕様書 v0.1(Phase 0)

MVPのゲームルールをここで確定する。実装・テストはこの文書を正とする。
名前はすべて仮のオリジナル名(原作のキャラ名・アイテム名は使わない)。

- 【確定】= 決定済み
- 【仮】= 数値は決めたが、実機で遊んで調整する

---

## 1. 試合の流れ
1. 設定画面で「必要スター数」「勝利数」「残機」を選ぶ
2. ラウンド開始: 2人がステージ両端付近の土管から登場【確定】
3. どちらかがラウンドに勝つまでプレイ
4. 勝者表示 → 勝利数を更新 → 規定の勝利数に届いていなければ次のラウンドへ
5. 規定の勝利数に先に届いた方が試合の勝者

### 設定項目
| 項目 | 選択肢 | 初期値 |
|---|---|---|
| 必要スター数 | 3 / 5 / 10 | **3**【確定】 |
| 勝利数(先取) | 1 / 2 / 3 | **3**【確定】 |
| 残機 | 3 / 5 / 無限 | **3**【確定】 |
| CPUの強さ | 弱い / 普通 / 強い | 普通【仮】 |

### ラウンドの勝ち方
- 必要スター数に先に到達した方が即勝利【確定】
- 相手が残機をすべて失った場合も勝利【確定】
- 時間制限なし【確定】

---

## 2. ビッグスター
| 項目 | 仕様 |
|---|---|
| 最初のスター | ラウンド開始2秒後に出現【仮】 |
| 同時に出ているスター | ステージに1個だけ(落としたスターは別扱い)【確定】 |
| 出現場所 | ステージごとに用意した出現候補地点からランダム。両プレイヤーから一定距離以上離れた地点を優先【仮】 |
| 次のスター | 取られてから10秒後に出現【確定】 |
| 取得 | 触れた瞬間に取得【確定】 |

---

## 3. スターを失う条件
失うスターは手持ちから減り、その場で弾んで飛び散る(手持ちが0なら何も起きない)。

| 条件 | 失う数 | 他の影響 |
|---|---|---|
| 相手に踏まれる | 1【確定】 | ダメージなし、少し沈む演出 |
| 相手のヒップドロップを受ける | 3【確定】 | 短時間動けなくなる(0.5秒)【仮】 |
| 敵・火の玉・トゲなどでダメージ | 1【確定】 | 1段階小さくなる。小さい状態ならミス扱い |
| ミス(穴に落ちる、小さい状態でダメージ) | **1【確定】** | 残機−1、土管から小さい状態で復帰 |
| 2人が横からぶつかる | 双方1ずつ【確定】 | ダメージなし、お互い弾かれる |

### 落としたスター
| 項目 | 仕様 |
|---|---|
| 誰が拾えるか | 誰でも(落とした本人も)【確定】 |
| 本人が拾い直せるまで | 1秒【仮】 |
| 消えるまで | **5秒**【確定】(消える直前の1.5秒は点滅)【仮】 |
| 被ダメ後の無敵 | 2秒間は再びスターを失わない【仮】 |

## 4. コインとアイテム
- 画面上部のカウンター「x/8」。8枚集めるとアイテムが画面上から自分の近くに落ちてくる【確定】
- 8枚達成でカウンターは0に戻る【確定】
- コインを取るとその場に今の枚数(例「3」)をポップアップ表示。8枚目は大きく強調【確定】
- ミスしてもコイン・スターは保持(残機のみ減る)【確定】
- ?ブロックからはコインまたはアイテムが出る【確定】

### アイテム(6種類)
| 仮名 | 効果 | 持続 |
|---|---|---|
| 成長アイテム | 大きくなる。ダメージを1回耐える | 被ダメまで |
| 炎アイテム | 火の玉を撃てる。当てた相手はスター1個を失う | 被ダメまで |
| 甲羅アイテム | ダッシュ中に甲羅に入って滑り、体当たりで相手のスター1個 | 被ダメまで |
| 縮小アイテム | 小さくなり高く跳べる、細い土管に入れる。踏んでもスターは奪えない【仮】 | 被ダメまで |
| 無敵アイテム | 無敵。触れた相手はスター1個を失う | 10秒【仮】 |
| 巨大化アイテム | 巨大化してブロックを壊して進む。触れた相手はスター1個を失う | 10秒【仮】 |

### 出やすさ(負けている側が強いアイテムを引きやすい)【確定・数値は仮】
「スター差」= 相手のスター数 − 自分のスター数

| スター差 | 成長 | 炎 | 甲羅 | 縮小 | 無敵 | 巨大化 |
|---|---|---|---|---|---|---|
| 0以下(同点・リード) | 30% | 25% | 15% | 20% | 5% | 5% |
| 1(1個負け) | 20% | 20% | 15% | 15% | 15% | 15% |
| 2以上(大きく負け) | 10% | 15% | 10% | 10% | 25% | 30% |

## 5. ステージ
- 左右はループ(右端を越えると左端から出る)【確定】。土管ステージだけはループなし
- MVPのステージは5種類: 草原・レンガ・氷・土管・城。まず草原1面から作る【確定】
- 敵は2種類: 歩くだけの敵、甲羅を持つ敵(踏むと甲羅になり、蹴れる)【確定】

## 6. 操作(スマホ)
| 操作 | 入力 |
|---|---|
| 移動 | 画面左の十字キー |
| ダッシュ / 火の玉 | 画面右のBボタン(押しっぱなしでダッシュ) |
| ジャンプ | 画面右のAボタン(長押しで高く跳ぶ) |
| ヒップドロップ | 空中で十字キーの下 |
| 壁キック | 壁に張り付いてジャンプ |
| 土管に入る | 土管の上で十字キーの下 |

## 7. 画面表示(HUD)
- 左上: 自分のスター数、残機
- 中央上: コイン「x/8」
- 右上: 相手のスター数、残機
- 最上部: ステージ全体を表す細いバー。2人とスターの位置を点で表示【確定】
- ラウンド終了時: 勝者表示と、2人の勝利数を丸マークで表示
