名前はすべて仮のオリジナル名(原作のキャラ名・アイテム名は使わない)。

## 1. 試合の流れ
1. 設定画面で「必要スター数」「勝利数」「残機」「CPUの強さ」「ステージ」を選ぶ
2. ラウンド開始: 2人がステージの土管から登場する【Wiki】
3. どちらかがラウンドに勝つまでプレイ
4. 勝者表示 → 2人の勝利数を丸マークで表示【動画】
5. 規定の勝利数に先に届いた方が試合の勝者【Wiki】

### 設定項目
| 項目 | 選択肢 | 初期値 | 出典 |
|---|---|---|---|
| 必要スター数 | 3 / 5 / 10 | 3 | 選択肢【Wiki/FAQ】、初期値【決定】 |
| 勝利数(先取) | 1 / 2 / 3 | 3 | 選択肢【Wiki】(FAQの1/3/5本勝負と同じ意味)、初期値【決定】 |
| 残機 | 3 / 5 / 無限 | 3 | 選択肢【Wiki/FAQ】、初期値【決定】 |
| ステージ | 5種類から選択 / ランダム | 草原 | 【Wiki/FAQ】 |
| CPUの強さ | 弱い / 普通 / 強い | 普通 | 【独自】 |

### ラウンドの勝ち方
| 条件 | 出典 |
|---|---|
| 必要スター数に先に到達した瞬間に勝利 | 【Wiki/FAQ】【動画】 |
| 相手が残機をすべて失ったら勝利 | 【Wiki/FAQ】 |
| 時間制限なし | 【決定】 |

## 3. 動きの数値
**方針: 原作の実装値を移植し、受け入れ条件テストで固定する。**(v6 で方針を変えた。以前は実機の感想を優先していた)
動画実測は参考として残す。測り方: 1マス=16ドット=動画の28.8px。ジャンプは地面の位置を毎フレーム検出して「地面からの高さ」で測った。

**v7(2026-09): 基準作品を New Super Mario Bros.(Nintendo DS) にした。**

> **動きの数値の正は [`docs/nsmb_ds_physics.md`](nsmb_ds_physics.md) に移した。**
> 値・出典・確度(exact / reimpl / measured / unknown)・単位換算・Jape独自仕様の一覧はあちらを見ること。
> 受け入れ条件は `tests/test_nsmb_feel.gd`。数値をずらすときは、まずあちらに1行足す。

v3〜v5 は実機の感想を数値に反映していたが、ひとつ直すたびに別の比率が崩れ、最後は
「立ちジャンプでハテナブロックに届かない(頭3.66マス < 4マス)」「高さの割に横に進みすぎ
(1回のジャンプで高さの4.25倍=14マス進む)」という状態になった。v5 で入れた「頂点でふわっと
浮く重力」も原作とは逆だった(原作は**飛び出し直後だけが軽く、頂点も落下も重い**)。
v6 で SMB3 の実装値へ移植して方式は正しくなったが、基準作品が違っていた。
v7 で NSMB DS の解析資料から、速度段・重力帯・ジャンプ先行入力・コヨーテタイムごと作り直した。

以下 v6 の記述は、方式を変えた経緯として残す。

### v6 の基準と出典(参考)

基準は **SMB3**。出典は [velipso/smb3-physics](https://github.com/velipso/smb3-physics)
(SMB3 の移動処理を読みやすい JavaScript に変換した **0BSD** = 実質パブリックドメインの実装)。
**数値だけ**を下の換算で取り込み、コードは GDScript で書き直している。

換算: 1マス=16px、60fps。`px/フレーム → マス/秒 = ×60/16`、`px/フレーム² → マス/秒² = ×3600/16`

| SMB3 の値 | 原表記 | 採用値 |
|---|---|---|
| ジャンプ初速(横の段で4段階) | -3.5 / -3.625 / -3.75 / -4.0 px/f | **13.125 / 13.594 / 14.063 / 15.0 マス/秒** |
| 軽い重力(飛び出し直後・ボタン保持中のみ) | 1/16 px/f² | **14.06 マス/秒²** |
| 重い重力(頂点・落下・離した後) | 5/16 px/f² | **70.31 マス/秒²** |
| 軽い重力が続く条件 | 上昇が 2 px/f 超 かつ ボタン保持 | **上昇 7.5 マス/秒 超 かつ 保持** |
| 最大落下速度 | 4 px/f | **15.0 マス/秒** |
| 歩きの最高速 | 1.5 px/f | **5.625 マス/秒** |
| ダッシュの最高速 | 2.5 px/f | **9.375 マス/秒** |
| 加速・摩擦 | 14/256 px/f² | **12.30 マス/秒²**(最高速まで0.77秒) |
| 切り返し(スキッド) | 32/256 px/f² | **28.125 マス/秒²** |

**高さは数値として持たない。** 初速と重力から決まる結果であり、テストが実測する:
立ちジャンプ **4.6マス**(頭5.5マス)、助走ジャンプ **6.5マス**(頭7.4マス)、
上昇0.65秒 / 落下0.53秒、助走ジャンプで進む距離 11.3マス(高さの1.72倍)。

### このゲーム独自の要素(SMB3 に無い。逸脱として記録)

| 要素 | 採用値 | 理由 |
|---|---|---|
| 横の速さが4段 | 2.5 / 5.625 / 7.5 / 9.375 マス/秒 | ユーザー要望「4段階くらいに分けたい」。段2・段4は SMB3 の歩き・ダッシュそのもの。段1(スティックを少し倒す)と段3(ダッシュ+少し倒す)が独自 |
| 3段ジャンプ | 初速 16.0 / 17.0(高さ約7.5 / 8.7マス) | 原作(NSMB)に存在【Wiki】。SMB3 には無いので数値は推測 |
| 壁すべり・壁キック | 落下3.0 / 横7.0 / 高さ4.0マス | 同上。入力制限16フレームは【TAS】 |
| ヒップドロップ | 溜め0.25秒・急降下20.0 | 同上 |
| 踏みつけの跳ね返り | 1.5 / 4.5マス | 同上 |
| 敵・落ちる物の重力 | 40 / 最大落下24 | プレイヤーの重力を変えても敵の挙動を変えないため別にしている |

### 数値を動かすときの決まり(v6以降)

**感想だけで数値を動かさない。** まず `tests/test_mario_feel.gd`(受け入れ条件)に、
観測できる量で1行足してから数値を変える。今ある条件:

| # | 条件 |
|---|---|
| 1 | 立ちジャンプで足元から4マスのハテナブロックに頭が届く |
| 2 | 助走ジャンプは6マスに届き、7.5マスには届かない |
| 3 | 歩き5.625 / ダッシュ9.375 マス/秒 |
| 4 | ダッシュの最高速まで約0.76秒 |
| 5 | 最大落下速度 15.0 マス/秒で頭打ち |
| 6 | 上昇のほうが落下より長く、上昇は0.75秒未満 |
| 7 | 短押しジャンプは通常の45%未満、それでも1マスは跳べる |
| 8 | 助走ジャンプで8マスの穴は越え、12マスは越えない |
| 9 | 助走ジャンプで進む距離は高さの2倍未満 |

ステージの寸法も原作の格子に合わせる: **ハテナブロックの行は足元から4マス上(y=5)**、土管の幅2マス。

## 5. スターを失う条件
失ったスターはその場で弾んで飛び散る。手持ちが0個なら何も起きない。

| 条件 | 失う数 | その他 | 出典 |
|---|---|---|---|
| 相手に踏まれる | 1 | ダメージなし | 【Wiki/FAQ】 |
| 相手のヒップドロップを受ける | 最大3(持っている分まで) | ダメージなし | 【Wiki/FAQ】 |
| 火の玉・蹴られた甲羅・爆弾 | 1 | ダメージあり | 【FAQ】 |
| 無敵・巨大化・甲羅状態の相手に触れる | 1 | ダメージあり | 【FAQ】 |
| 立っているブロックを下から叩かれる | 1 | 少し跳ね上がる | 【FAQ】 |
| 敵・トゲに当たる | 1 | ダメージあり | 【Wiki】 |
| 穴に落ちる | 1 | 残機−1 | 【決定】(WikiとFAQが食い違うため) |
| 2人がぶつかる | 双方1ずつ | ダメージなし、お互い弾かれる | 【Wiki】を採用(FAQは「双方ダッシュ中のみ」) |

- スターを失った後の無敵時間: 1秒。この間はスターを失わず、ぶつかりも発生しない【FAQ】
- ラウンド開始時と、ミスから復帰した直後は2秒間無敵【決定・調整】(登場直後に敵に当たってミスするのを防ぐため)
- 縮小状態で相手を踏んでもスターは奪えない(ヒップドロップなら奪える)【FAQ】
- 縮小状態は火の玉1発でミス【FAQ】

### 落としたスター
| ルール | 出典 |
|---|---|
| 誰でも拾える(落とした本人も) | 【決定】 |
| 落とした本人は0.5秒間拾えない | 【決定・調整】 |
| 5秒で消える。消える前の1.5秒は点滅 | 5秒は【決定】、点滅は【決定・調整】 |

原作の確率は不明。この作品では、負けている側ほど強いアイテムが出やすくする。

| スター差 | 成長 | 炎 | 甲羅 | 縮小 | 無敵 | 巨大化 |
|---|---|---|---|---|---|---|
| 0以下(同点・リード) | 30% | 25% | 15% | 20% | 5% | 5% |
| 1(1個負け) | 20% | 20% | 15% | 15% | 15% | 15% |
| 2以上(大きく負け) | 10% | 15% | 10% | 10% | 25% | 30% |

## 8. ステージ
